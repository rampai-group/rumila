## Temuan dan perbaikan

- **M31 jam:** [sebelumnya](bukti/sebelum-jam.png), jam emoji kecil dan tanpa angka, dengan ruang kosong luar panel hingga 44% HP / 55% iPad pada ronde awal. Kini 20 waktu analog menggunakan SVG berangka, jarum pendek/jam dan panjang/menit kontras. Jarum jam berada di antara angka pada setengah jam. Kartu dan rak mengikuti kepadatan; posisi rak tidak meloncat ketika kartu dipindahkan. Ronde terpadat delapan kartu / sepuluh rak selesai pada semua ukuran. Kunci waktu digital/analog tetap sama dan cocok dengan rak.
- **M32 kalender:** hari/bulan, titik mulai, dan pergantian pekan/tahun sesuai kunci. Kedua varian ditamatkan dengan ketuk dan seret, termasuk lima slot. Tidak perlu perubahan konten atau mekanik.
- **M33 debugging:** seluruh 48 grid memiliki solusi satu perubahan yang mencapai bintang tanpa perintah tersisa. Pada UI diuji perubahan angka Ulangi, isi Ulangi, dan blok di luar Ulangi. Kedua varian selesai pada tiga ukuran; tidak perlu perubahan mekanik.
- **M34 air/daratan:** ilustrasi tempat dari perbaikan sebelumnya dan kunci 23 benda dipertahankan. [Sebelumnya](bukti/sebelum-bumi.png), satu kartu HP kecil dengan hampir separuh layar kosong. Kartu terakhir kini lebih besar dan tujuan tetap terjangkau; enam/lima kartu pada ronde padat tetap muat.
- **M35 Carroll:** semua 28 benda diperiksa terhadap dua ciri sekaligus. Perbaikan tujuan HP dari sesi sebelumnya dipertahankan. [Sebelumnya](bukti/sebelum-carroll.png), gambar dan sisa kartu kecil di tablet. Kartu tablet serta kartu terakhir HP diperbesar; semua tujuan menerima seret, termasuk ronde delapan kartu kuning dan enam kartu merah.

## Validasi dan batas pengujian

865 tes dalam 103 berkas lulus, 810 paket valid, TypeScript `--noEmit`, lint berkas perubahan, serta `git diff --check` lulus. Tes baru memeriksa peta gabungan dan koordinat kedua jarum untuk seluruh 20 waktu analog. Tes sebelumnya tetap memeriksa seluruh kalender, 48 program debugging, ilustrasi air/daratan, dan kunci Carroll.

Pengukuran tampilan awal semua ronde serta tahap akhir pilah tidak menemukan teks terpotong, elemen keluar samping, atau gulir panggung. Instruksi panjang HP dibuka melalui tombol baca lengkap dan direkam. Sepuluh tombol audio berhasil memuat HTTP 200 dan berkas dapat didekode dengan durasi positif (`audio.json`); bukan evaluasi pelafalan melalui pendengaran. Tidak ada perubahan narasi.

Interaksi memakai UI ketuk, keyboard, dan seret. Props soal navigasi/kalender dibaca untuk mengidentifikasi ronde, tanpa mengubah state permainan. Kunci kalender diperiksa terhadap siklus, program diuji dengan simulator terpisah, lalu hasil UI dicocokkan dengan event `attempt` dan `activity_end`. Tidak memakai akun anak atau mengirim progres ke server.

Bukti berasal dari server worktree sendiri pada port 39864. Ringkasan 30 sesi ada di `hasil.json`; 90 screenshot hasil/padat/tahap akhir, tujuh instruksi panjang, dan tiga pembanding sebelum perbaikan ada di `bukti/`. Bukti mentah setiap ronde: `/tmp/m31-verified`.
