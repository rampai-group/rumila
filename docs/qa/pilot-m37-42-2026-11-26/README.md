## Temuan dan perbaikan

1. **M38: palet pola membuat panggung bergulir.** Ukuran gambar yang membesar dan label panjang tidak terhitung penuh; kartu palet juga tidak memakai lebar yang dipakai dalam perhitungan. Pada baseline, pola tangan/bintang bergulir hingga 213 px di HP dan 116 px di iPad pendek. Lebar palet dan alokasi tinggi kini menghitung skala gambar serta label beberapa baris, khusus kompetensi pola Pilot. Setelah perbaikan, semua ronde kedua paket di tiga ukuran muat tanpa gulir vertikal.
2. **M39: gambar belum menunjukkan sambungan.** Emoji mouse/headphone tidak memperlihatkan kabel, drone berupa helikopter, bel pintu berupa lonceng, kamera keamanan berupa kamera video. Kedua paket kini memakai SVG perangkat dengan kabel terhubung ke perangkat pasangan atau gelombang sinyal. Mouse/proyektor/printer/keyboard tersambung ke laptop, gitar/mikrofon/keyboard musik ke pengeras suara, TV ke antena. Seluruh 26 kartu mendapat ilustrasi; instruksi dan kunci dipertahankan.
3. **M39–40: rak tablet terlalu jauh di ronde padat.** Label perangkat panjang dan tiga baris kartu mendorong rak keluar layar (baseline M39 hingga 278 px pada iPad pendek). Khusus perangkat Pilot, empat kolom, tinggi kartu dan ukuran gambar/label disesuaikan. Kedua rak dan kartu tetap terjangkau; kartu terakhir dan isi rak ikut diperiksa.
4. **M40: gambar tidak sesuai bendanya.** Wajah robot generik untuk penyedot debu/pengantar makanan, kotak untuk robot kardus, kayu untuk patung robot, serta helikopter untuk drone paket diganti ilustrasi tugas/bentuk masing-masing. Robot pengecat menampilkan semprotan ke mobil, robot pabrik lengan penjepit; kendaraan otomatis menampilkan sensor. Kunci tetap membedakan mesin yang bekerja mengikuti program dengan mainan/patung atau perkakas biasa.
5. **M41: garis awal jengkal bergeser setengah ketebalan garis.** Posisi kiri dikoreksi sebesar `2 × skala` agar pusat garis tepat pada batas kiri satuan pertama, konsisten dengan garis akhir. Batas telapak bersebelahan dan pusat kedua garis diverifikasi dengan toleransi <1 CSS px setelah animasi selesai. Penggaris kubus mempertahankan perbaikan sesi sebelumnya: kedua garis berbagi pembagian lebar dengan 12 kubus, termasuk soal yang mulai setelah kubus pertama; seluruh ronde pada ketiga ukuran lulus.
6. **M42: tidak perlu perubahan mekanik.** Perbaikan sesi sebelumnya tetap dipertahankan: sebelum “Mulai hitung”, pengunjung tidak lewat dan tabel belum aktif; QA menunggu 6 detik sebelum mulai pada setiap ronde. Setiap pengunjung dicatat saat gilirannya, termasuk jenis sama berturut-turut (52 dari 60 ronde mengandung pengulangan beruntun). Jalur, semua baris tabel, dan tombol tampil bersamaan tanpa gulir di ketiga ukuran; tombol “Selesai” baru aktif sesudah semua lewat. Kedua paket misi terakhir mencapai hasil 10/10.

## Soal, kunci, dan gambar

- M37: 10 pertanyaan prediksi panas/teduh/dingin diperiksa bersama pilihannya. Es krim tetap beku memakai **bagian pembeku**, susu dingin memakai kulkas, bermain di luar paling sejuk di bawah pohon. Pasangan cepat/lambat membandingkan benda/kondisi yang dijelaskan pada kartu. Tidak ditemukan kunci salah.
- M38: jawaban dihitung dari unit pola yang terlihat (panjang unit 2 atau 3), termasuk ukuran besar/kecil, arah, tiga slot kosong dan pengecoh. Perbedaan skala tetap dipertahankan saat layout dipadatkan.
- M39–40: seluruh label dan kategori ditelaah; semua gambar SVG yang muncul dicek variannya dan batasnya terhadap kartu. Soal tetap menyebut konteks otonom pada kendaraan/robot agar tidak menyimpulkan bahwa setiap mobil atau drone adalah robot.
- M41: jawaban kubus dihitung dari batas gambar dan kotak satuan yang terlihat; jengkal ditempatkan melalui tombol dan diverifikasi posisinya sebelum memilih angka. Seluruh angka dinilai benar oleh mesin.
- M42: catatan berasal dari urutan pengunjung yang sedang lewat di UI, bukan pengisian total akhir sekaligus. Kejadian sejenis beruntun mendapat ketukan terpisah.

## Reproduksi dan bukti

[Hasil terstruktur per ronde](results.json) memuat seed, viewport, knob adaptif, jawaban, pengukuran dan hasil. Screenshot hasil dan ronde padat untuk **seluruh 36 kombinasi** disimpan di folder `screenshots/`.

Jalankan server lokal pada port 3878, lalu:

```sh
RUMILA_PLAYWRIGHT_MODULE=/absolute/path/to/playwright-core/index.mjs \
RUMILA_QA_OUTPUT=/tmp/rumila-pilot-m37-42-qa \
node scripts/qa/pilot-m37-42.mjs
```

Script menggunakan jam virtual untuk mempercepat waktu antar-ronde/pengunjung; interaksi jawaban tetap lewat tombol/kartu UI dan hasil diverifikasi dari event lokal serta layar hasil. Tidak menulis data anak/server. Variabel opsional `RUMILA_QA_DEVICE`, `RUMILA_QA_MISSION`, dan `RUMILA_QA_SLUG` mempersempit tes ulang. Tanpa variabel modul, paket `playwright-core` harus tersedia pada lingkungan Node. Script bukan dependency runtime aplikasi.

Validasi lokal: 845 tes dalam 99 berkas, validasi 810 paket, TypeScript, lint berkas yang diubah, dan build produksi. Build memiliki satu warning hook lama di `src/components/sheets.tsx`; tidak ada error build. Sinkronisasi dengan `origin/main` **6044a55c** menyertakan PR #238 (layar masuk) dan #239 (QA M21–25). Konflik satu baris jumlah kolom menggabungkan aturan kedua sesi; katalog diregenerasi dari sumber gabungan. Tes 845/845 dan permainan M39–40 pada tiga ukuran diulang setelah merge. Status PR dan verifikasi deployment dilaporkan setelah rilis.

Jengkal panjang di HP menggunakan **gulir horizontal bawaan** agar satuan tetap cukup besar untuk disentuh. Kedua ujung diperiksa bergantian; lihat [ujung kanan HP](screenshots/m41a-hp-ujung-kanan.png), [iPad](screenshots/m41a-ipad-ujung-kanan.png), dan [iPad pendek](screenshots/m41a-ipad-pendek-ujung-kanan.png). Tidak ada gulir vertikal pada panggung akhir (toleransi pembulatan layout ≤4 px). Label tersembunyi untuk pembaca layar pada kubus sengaja berukuran 1 px, bukan teks UI yang terpotong.
